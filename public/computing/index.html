Operating System

After many years of distro-hopping, I landed on Debian about a year ago. I use it for it’s stability, package support, and reliability. I do not usually mind the older packages, although if I do need newer versions, I either use AppImages, .deb files, or simply build from source. On my desktop I use KDE, but have used basically everything else in the past, including tiling window managers. I simply like the KDE suite of GUI applications.

On my laptop, which is what I use most often, I run Windows 11. Despite this, I have a Debian WSL (Windows Subsystem for Linux) environment installed. This is where I do all of my development work. I have found WSL works impressively well, especially with the new Windows Terminal app.

Text Editors

When working on a big project with large directories, or media files, I opt for a more complete text-editor/IDE such as VSCode. It integrates well with WSL. When working on smaller projects or simply editing files, I use a ligher, terminal based text editor. My current go-to is the Micro text editor. It shares many of the same keyboard shortcuts as VSCode and it’s very easy to start using. Recently I have been dabbling in NeoVim. I haven’t had the opportunity to learn the complete ins and outs, nor have I done any configuation, but I do like the modal editing scheme. I enjoy rarely having to take my hands off the home row of the keyboard.
